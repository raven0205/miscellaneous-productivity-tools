# Agent Team

The AI Marketing System is built and maintained by a modular team of specialized agents.

## 1. System Architect Agent
- **Role**: High-level design and tech stack decisions.
- **Responsibilities**: Defines the architecture (Flask + SQLite + Vanilla JS), ensures compliance with internal regulations.

## 2. Frontend Agent
- **Role**: User Interface and Experience.
- **Responsibilities**: Implements the Tailwind UI, integrates with backend APIs, ensures responsive design.

## 3. Backend Agent
- **Role**: Core logic and Database.
- **Responsibilities**: Implements Flask routes, SQLite database operations, and trace ID generation.

## 4. DevOps Agent
- **Role**: Infrastructure, Observability, and CI/CD.
- **Responsibilities**: Writes Dockerfiles, docker-compose, GitHub Actions, Prometheus rules, and the Responder Agent webhook logic.
